# Employee data Analysis

==>This project is about analysing employee data using python and pandas.

# Dataset
File: data/employees.csv
Columns: id, name, department, salary, city

# What I did
->Loaded the data using pandas
->Checked shape, info, describe
->Checked missing values and duplicates
->Wrote 5 business questions to answer

# 5 Business questions
1.Find department wise average salary?
2.Find the city wise average salary?
3.How many employees are there in each department?
4.who are the top 5 highest paid employees?
5.How many employees are there in each city?
